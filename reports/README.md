# Reports

У цій папці зберігаються звіти, рисунки, таблиці та інші результати практичних робіт.

- `PR0N_control_questions.md` — відповіді на контрольні запитання;
- `iris_statistics.csv` — описова статистика (робота 1);
- `preprocessing_summary.csv`, `class_mapping.json` — звіт про очищення та словник класів (робота 2);
- `model_metrics.csv` — метрики моделей (робота 3);
- `figures/` — рисунки всіх робіт.
