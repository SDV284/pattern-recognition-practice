# Практична робота 1 — відповіді на контрольні запитання

**Студент:** Святішенко Дмитро, група ІН-32/2

1. **Що таке Google Colab?** Хмарне середовище від Google для створення та виконання Jupyter Notebook у браузері без локального встановлення Python; код виконується на віддаленій віртуальній машині.
2. **Що таке Jupyter Notebook?** Інтерактивний документ (файл `.ipynb`), що поєднує комірки з кодом, результати їх виконання (таблиці, графіки) і текстові пояснення в Markdown.
3. **Які два основні типи комірок використовуються в Notebook?** Code — комірка з кодом Python; Text (Markdown) — текстова комірка з поясненнями.
4. **Як запустити комірку?** Кнопкою запуску ліворуч від комірки або комбінацією клавіш Shift + Enter; усі комірки — через Runtime → Run all.
5. **Для чого призначений файл README.md?** Це головний опис репозиторію: назва, автор, призначення, структура, опис робіт, інструкція із запуску та посилання на основні файли. Його першим бачить користувач на GitHub.
6. **Що таке pandas DataFrame?** Двовимірна таблична структура даних бібліотеки pandas з іменованими стовпцями та індексом рядків; кожен стовпець може мати власний тип даних.
7. **Що є рядком таблиці?** Один об'єкт (приклад) вибірки — у наборі Iris це одна квітка.
8. **Що є стовпцем таблиці?** Одна характеристика об'єктів — ознака або цільова змінна.
9. **Що таке об'єкт у задачі машинного навчання?** Окремий досліджуваний приклад, якому відповідає один рядок таблиці.
10. **Що таке ознака?** Вимірювана характеристика об'єкта, яка подається на вхід моделі (окремий стовпець таблиці).
11. **Що таке цільова змінна?** Значення, яке модель має навчитися прогнозувати за ознаками.
12. **Що є об'єктом у наборі Iris?** Одна квітка ірису.
13. **Які ознаки містить набір Iris?** Довжина чашолистка, ширина чашолистка, довжина пелюстки, ширина пелюстки (усі в сантиметрах).
14. **Яка цільова змінна використовується у роботі?** `species` — вид ірису (setosa, versicolor, virginica).
15. **Чому задача Iris є задачею класифікації?** Бо цільова змінна категоріальна: потрібно віднести об'єкт до одного зі скінченної множини класів, а не спрогнозувати неперервне число.
16. **Чому ця задача є багатокласовою?** Бо класів більше двох — три види ірису.
17. **Для чого використовується метод head()?** Для перегляду перших рядків таблиці (за замовчуванням п'яти), щоб швидко перевірити дані.
18. **Для чого використовується метод tail()?** Для перегляду останніх рядків таблиці (за замовчуванням п'яти).
19. **Що повертає властивість shape?** Кортеж `(кількість рядків, кількість стовпців)`; для Iris — `(150, 5)`.
20. **Для чого використовується метод info()?** Показує кількість рядків, назви стовпців, кількість непорожніх значень, типи даних і обсяг пам'яті.
21. **Яку інформацію повертає метод describe()?** Для числових стовпців: count, mean, std, min, 25 %, 50 % (медіана), 75 %, max.
22. **Як знайти пропущені значення?** `data.isna().sum()` — кількість пропусків у кожному стовпці; `data.isna().sum().sum()` — загальна кількість.
23. **Як перевірити наявність дублікатів?** `data.duplicated().sum()` — кількість рядків, що повністю повторюють попередні (в Iris — 1).
24. **Для чого використовуються гістограми?** Щоб побачити форму розподілу числової ознаки: діапазон, центр, розкид, асиметрію, наявність кількох груп і викидів.
25. **Чому важливо аналізувати розподіл об'єктів за класами?** Незбалансовані класи спотворюють навчання і метрики (модель «підлаштовується» під більший клас), тому баланс потрібно знати заздалегідь.
26. **Чим ознаки X відрізняються від цільової змінної y?** X — матриця вхідних даних (150 × 4), за якими робиться прогноз; y — вектор відповідей (150), який потрібно прогнозувати.
27. **Чому важливі дані потрібно зберігати на Google Drive або GitHub?** Середовище Colab тимчасове: після завершення сеансу його файли й змінні видаляються.
28. **Чому перед здаванням необхідно повторно виконати всі комірки?** Щоб переконатися, що Notebook працює зверху вниз без помилок і прихованих залежностей від порядку запуску, а всі результати й графіки збережено у файлі.
29. **Які файли містить створений навчальний ML-проєкт?** `README.md`, `.gitignore`, папку `notebooks/` (README.md, PR01_Sviatishenko_D.ipynb), папку `data/` (README.md, iris.csv), папку `reports/` (README.md, iris_statistics.csv, рисунки, відповіді на запитання).
