# Data

У цій папці зберігаються невеликі навчальні набори даних.

- `iris.csv` — початковий набір Iris (практична робота 1);
- `iris_dirty.csv` — контрольовано пошкоджена версія набору (практична робота 2);
- `processed/iris_cleaned.csv` — очищений набір;
- `processed/X_train.csv`, `processed/X_test.csv` — ознаки навчальної та тестової вибірок;
- `processed/y_train.csv`, `processed/y_test.csv` — коди класів навчальної та тестової вибірок.

Не дозволяється додавати конфіденційні, приватні або персональні дані.
