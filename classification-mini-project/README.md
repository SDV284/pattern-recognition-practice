# Порівняння класичних моделей класифікації

Мініпроєкт практичних робіт 4–7 з дисципліни «Розпізнавання образів та класичне машинне навчання».

**Студент:** Святішенко Дмитро, група ІН-32/2

## Постановка задачі

За характеристиками пацієнта визначити, чи належить він до класу з наявністю ознак серцевого захворювання
(бінарна класифікація, позитивний клас — 1). Основна метрика — F1 позитивного класу.

## Набір даних

[Heart Disease, UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/45/heart+disease) —
`processed.cleveland.data`, збережений як `data/heart_disease.csv` (303 об'єкти, 13 ознак, `target` 0/1).
